# 🦖 Pixel Dino Game

A simple Dino game built with Python and Pygame. The player controls a pixel dino that jumps over obstacles to score points. I made this project to practice Python basics and game development.

## 📦 Technologies
- Python
- Pygame

## 🦄 Features
- Press **Space** to jump.
- Avoid obstacles to increase your score.
- Simple graphics using rectangles (easy to understand for beginners).
- Game Over message when you collide with an obstacle.

## 👩🏽‍🍳 The Process
I started by creating a rectangle to represent the dino. Then I added jumping mechanics using gravity and velocity. After that, I created obstacles that move across the screen. Finally, I added collision detection and a score counter.

## 📚 What I Learned
- How to use the `pygame` library.
- How to handle keyboard input.
- How to use rectangles for simple graphics.
- How to detect collisions between objects.
- How to update the screen in real time.
